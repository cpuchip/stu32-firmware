# the blueprint's, written before src ran (the baseline B and the jumps J were run on 430eafd's build first:
# work/stu-indirect-evidence/). i is the index; (i) names the unnamed registers 0-800 by its integer part; NO REGISTER
# for an index that names nothing; in XEQ, GTO and FN=, i 1-26 names label A-Z; I and J are plain letters.
