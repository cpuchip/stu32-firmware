# i is the index (AB_VAR_SI), (i) is indirect through it; the keys that make them in STU are soroban's own vectors' and
# screen_test's to check, not this file's.
# Registers: (i) names unnamed register int(i), 0 to 800. NO REGISTER: i negative, above 800, complex; a read above the
# defined range. I and J are plain letters in STU. Jumps (decision 102): XEQ, GTO (i) with int(i) 1 to 26 name labels
# A to Z; NO REGISTER for 0, 27 up, negative, complex; NONEXISTENT for a label not in memory.
