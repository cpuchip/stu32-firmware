# is the worksheet. Read by abacus #14043's grammar from screen_lines: %PAGEN=n the page's lines above the levels (the dropped
# line counts one, a two-line row two), %PAGE-k=LEFT|VALUE (k = 1 the lowest; LEFT the op's name as list.c's, an ALG row's
# text, empty for a typed number; VALUE as a level formats it; blanks _, an empty side _ alone), %LEVELS the levels drawn
# top to bottom (none off STU's home, - in ALG), %PAGETOP the dropped line's count or -. Each expectation below was worked
