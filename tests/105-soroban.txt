# Unit 105 (work/token-parentheses.md at 7ffc6a5; abacus #17893, rulings #17900; Michael's T136 A74, "Token's own
# parentheses"): the indirect tokens drawn with their own tighter pair, ⟮ ⟯ (U+27EE, U+27EF), so a token never draws
# as the user's typed ( I ). Each T line is a token, each U line the same letter typed in the user's parentheses with the
# cursor after them; %LOOK=!T compares the whole frame (it was 0 pixels apart on every pair at 8c4fad7, look-today.out).
# The texts stay ASCII (R2): each pair's %XLINE or %XDRAWN is the same on both lines. %XDRAW is the cells drawn, so it
# shows the pair. Every expectation was read on the prototype (work/token-parentheses-evidence/).
