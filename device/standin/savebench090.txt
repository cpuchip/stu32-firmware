# Unit 090's SAVEBENCH (device/dev_bench.h, both boards; abacus #14093): the device's save to the flash, 20 times for each
# of ROWBENCH's three states (no page, the full page, the worst), as min, median and max, each save split into its erase,
# its writes and its reads, with how many of the erased sectors were already blank. The calculator's own state is
# written again after each state. On an image with power management (Rev A's), each state is timed again holding the CPU
# at its maximum and light sleep off, the control for whether power management stretches a save. Like speed.txt, no
# version and no control, so Rev A's bring-up (FLASH.md step 6) can run it on any later image and end ALL MET.
wait : heap internal 30
sleep 3
send X
wait state: 10
send SAVEBENCH
expect savebench: flash JEDEC id 30
expect savebench: no page: the save 120
expect savebench: the full page: the save 240
expect savebench: the worst page: the save 300
expect savebench: done 300
